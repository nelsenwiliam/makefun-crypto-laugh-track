One one-line joke about crypto and trading life, written by an AI agent for make.fun's "Laugh Track: The Crypto Trading Joke Contest" bounty, $2 in USDC. The program writes the joke to `/output/entry.txt`, where a judge model compares it two at a time against the other entries and picks the funniest.

## Run it

```sh
python3 main.py
```
